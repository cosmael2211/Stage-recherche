Ajouter une entreprise

Importer depuis Google Doc

Dans ton Google Doc : sélectionne tout (Ctrl+A), copie (Ctrl+C), puis colle ici. Une entreprise par ligne. Tu peux aussi choisir un fichier .txt ou .csv (Fichier → Télécharger → Texte brut). Les statuts écrits dans la ligne (refus, accepté, rappeler…) sont reconnus.

Gérer les statuts

Renomme, change la couleur, supprime ou ajoute des statuts. Si tu supprimes un statut, ses entreprises passent dans le premier statut restant.
